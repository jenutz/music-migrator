Moving a library

The app takes a playlist from one service, looks the same tracks up on another, lets you pick from the candidates, and delivers them in the original order.

  1. Press Log in on a service — the token stays on this machine.
  2. Import snapshots that service's library into a dated playlist.
  3. Press Export on a playlist to create a target on another service.
  4. Match the tracks one by one, then deliver the chosen ones.

No accounts: this is a one-person tool and everything lives in data/app.db.
